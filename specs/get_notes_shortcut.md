# Get 筆記錄音快捷指令（Layer 3）

這份文件定義「Get 筆記錄音（一鍵返回）」iOS 快捷指令的結構與行為。
此快捷指令是 Life OS 的 Layer 3 入口之一，負責從 Get 筆記 App 抓取語音轉寫結果，並交給 OpenClaw `/log` 指令寫入。

---

## 定位

| 項目 | 說明 |
|---|---|
| Layer | 3（輸入入口） |
| 設備 | iPhone |
| channel | `get_notes` |
| media_type | `voice_transcript` |
| device | `iphone` |

---

## 步驟定義

| 步驟 | 動作 | 說明 |
|---|---|---|
| 1 | 打開 Get 筆記開始錄音 | 跳轉至 Get 筆記 App，使用者在 App 內完成語音錄製與轉寫 |
| 2 | 等待返回 | 暫停執行，等候使用者手動返回快捷指令（一鍵返回） |
| 3 | 取得剪貼板內容 | 讀取 Get 筆記在轉寫完成後自動複製到剪貼板的文字 |
| 4 | 將「原始表達」變數設為剪貼板 | 暫存轉寫結果，供後續步驟引用 |
| 5 | 顯示提示「錄製結束後繼續」 | 確認使用者已完成錄製，繼續執行後續的 OpenClaw 呼叫流程 |

---

## 資料流

```
使用者語音
  → Get 筆記（錄音 + 轉寫）
  → 自動複製至剪貼板
  → 快捷指令讀取剪貼板 → 存入「原始表達」變數
  → 呼叫 OpenClaw /log（raw_content = 原始表達, device = iphone, channel = get_notes, media_type = voice_transcript）
  → OpenClaw 寫入飛書 Bitable + AI 打標
  → 回傳確認訊息
```

---

## 傳入 OpenClaw 的固定參數

| 參數 | 值 | 說明 |
|---|---|---|
| `raw_content` | `原始表達` 變數內容 | 來自剪貼板的語音轉寫結果，一字不改 |
| `device` | `iphone` | 固定值 |
| `channel` | `get_notes` | 固定值 |
| `media_type` | `voice_transcript` | 固定值 |
| `type_tag` | （選填）| 可在快捷指令中加入選單讓使用者人工選擇；未選則由 AI 自動判斷 |

---

## 設計說明

- **Get 筆記的剪貼板機制**：Get 筆記在錄音轉寫完成後，會自動將轉寫文字複製到剪貼板。快捷指令以此為橋接點，不需要 URL Scheme 或 x-callback-url，降低設定複雜度。
- **一鍵返回**：使用「等待返回」動作，使用者在 Get 筆記完成錄音後只需切回快捷指令，流程自動繼續，達到最少操作步驟。
- **原始表達變數**：以變數暫存轉寫內容，確保後續步驟引用時內容不因剪貼板被覆蓋而遺失。
