# Type Tag Library

Context Event 的類型標籤對照表。這份表是動態資產，會隨時間增加新類型。

## 設計原則

- 每個類型有一個固定 emoji（代表這個類型本身）
- AI 可在此基礎上根據 raw_content 細化選擇更精準的 emoji，但只能在該類型的 emoji 範圍內選
- 新增類型需同步更新此表，並記錄日期

---

## 類型對照表

| key | 中文標籤 | 固定 emoji | 說明 | 關鍵詞提示（供 AI 判斷用）|
|---|---|---|---|---|
| `insight` | 收穫與反思 | ✅ | 學習後、事件後的心得、回顧、領悟 | 發現、領悟、原來、回顧、事後、心得、複盤 |
| `feeling` | 有感而發 | 🥰 | 當下湧現的情緒、感受、感動、觸動 | 感覺、覺得、情緒、開心、難過、感動、觸動、突然 |
| `self` | 對自己 | 😘 | 自我關係、身體感受、心理狀態、自我對話 | 我今天、我發現自己、身體、睡眠、狀態、對自己 |
| `daily` | 日常碎碎念 | 👱‍♀️ | 生活流水帳、行程、日常事件 | 今天去了、吃了、買了、看了、行程、日常、出門 |
| `family` | 家庭 | 👥 | 與家人的互動時刻、家庭事件 | 媽媽、爸爸、家人、孩子、寶寶、家裡、家庭 |
| `money` | 與錢錢戀愛 | 💰 | 財務、消費、收入、金錢觀察 | 錢、花了、買了、收入、支出、財務、投資、消費 |
| `work` | 業務與工作 | 💼 | 電子報、客戶、業務場景、工作事件 | 電子報、客戶、業務、工作、開會、項目、進度 |

---

## AI 打標規則

1. 以 `raw_content` 的**主要意圖**判斷類型，不以關鍵詞硬匹配
2. 若同時觸發多個類型，選**最主要**的一個
3. 若真的無法判斷，標記為 `daily`（保底類型）
4. 人工選的 `type_tag` 和 AI 選的 `type_tag_ai` 分開儲存，**不互相覆蓋**

## 邊界澄清（容易混淆的情況）

| 情況 | 正確分類 | 說明 |
|---|---|---|
| 「今天學了 XX，覺得很有啟發」 | `insight` | 重點是學習後的領悟，不是當下情緒 |
| 「突然覺得自己好累，不知道為什麼」 | `feeling` | 重點是當下情緒湧現，不是自我分析 |
| 「我最近發現我對批評很敏感」 | `self` | 重點是對自己的觀察與關係 |
| 「跟媽媽打電話，她說腰不好，我好擔心」 | `family` | 事件主體是家人，擔心是附帶情緒 |
| 「客戶說這個月想暫停合作」 | `work` | 業務事件，不是個人情緒 |
