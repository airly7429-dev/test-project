# 佳佳學姊｜整理變現

這是一個從佳佳學姊在《房間勇者村》第二期第一天的具體行動，蒸餾出的「整理後讓物品繼續流動」方法 Skill。

它目前是小範圍、證據限定的 v0.1，不是完整的人物分身，也不代表佳佳學姊的全部觀點。

## 使用邊界

先讀 `references/evidence.md`，區分三種內容：

1. **已核對行動**：佳佳整理後，將清出的物品直接掛上二手拍賣平台。
2. **使用者觀察**：使用者將此行動理解為資源再利用與變現，並稱她為「賣貨女郎佳佳」。
3. **待驗證假設**：價格判斷、平台選擇、拍照方式、成交率、她是否一貫如此處理物品，目前都沒有足夠資料。

不要把第 2、3 類寫成佳佳學姊的原話或已驗證方法。

## 何時使用

當使用者想要：

- 把整理出的物品轉成二手出售、資源再利用或收入；
- 依照「佳佳學姊／賣貨女郎」的案例設計整理流程；
- 將整理紀錄拆成「留下、轉贈、丟棄、出售」的下一步；
- 為清出的物品產出二手平台標題、描述、價格待確認欄位或上架清單。

如果使用者只是想整理房間、沒有處理物品流向，不要強行加入變現。

## 核心鏡片

整理不是終點。清出的物品若仍有可交換價值，可以被安排下一個去處，讓空間釋放同時連到資源再利用與變現。

這句是根據一個案例提煉出的**暫定模型**，不是佳佳學姊已被多次驗證的完整信念。

## 工作流程

### 1. 先鎖定一個小區域

不要一開始承諾整理整個家。請使用者指定一個抽屜、一個箱子、一層架子或一小批物品，並說明今天希望處理到哪裡。

### 2. 讓物品離開原位並做四向分流

對每件物品暫分為：

| 去向 | 判斷問題 | 下一步 |
|---|---|---|
| 留下 | 目前仍會使用，或有清楚的生活用途嗎？ | 放回固定位置 |
| 轉贈 | 自己不用，但有人可能需要嗎？ | 記錄對象或捐贈管道 |
| 丟棄 | 已損壞、過期或沒有合適去處嗎？ | 依規定處理 |
| 出售 | 仍有可交換價值，且值得花時間處理嗎？ | 進入二手上架清單 |

「值得花時間」是工作上的暫定判斷，不要說成佳佳學姊已明確提出的規則。

### 3. 對出售物品做最小上架準備

為每件出售物品建立一列資料：

```text
物品：
品牌／型號：
使用狀況：
瑕疵或缺件：
照片：待補／已補
預計價格：待確認
取貨或寄送方式：待確認
上架狀態：未上架／已上架／已售出／未成交
```

如果缺少品牌、尺寸、狀況、照片或價格，不要自行補寫；列出待補欄位即可。

### 4. 把「直接上架」視為一個可觀察動作

佳佳案例的可複用核心不是「把東西堆到待售區」，而是把清出來的物品往二手平台推進。若使用者已經確認要出售，就協助完成：

1. 整理現有資訊；
2. 產出標題與描述草稿；
3. 列出價格與交付方式待確認項目；
4. 等使用者確認後，才進行任何外部上架或發布。

不要把「已產出草稿」說成「已上架」，也不要未經確認代替使用者發布。

### 5. 回收結果，避免把一次行動誇大成模式

完成後只記錄實際狀態：整理了什麼、上架了什麼、是否成交、花了多少時間、使用者的感受。至少累積數次案例後，才討論哪些條件可能穩定有效。

## 回應格式

處理一批物品時，依序輸出：

1. **本次小區域與目標**
2. **四向分流表**
3. **出售清單**
4. **可直接使用的上架草稿**
5. **待使用者確認的欄位**
6. **本次實際證據與尚不能確定的部分**

若資料不足，先做清單和待補欄位，不要為了完整而編造價格、狀況、需求或成交結果。

## 表達方式

- 說「這次案例顯示」或「可以先試」，不要說「佳佳學姊的方法就是」。
- 保留使用者提供的原話與物品事實；AI 的判斷另放在「暫定做法」或「待驗證」中。
- 只把整理、分流、上架素材與結果寫進輸出，不延伸成對佳佳學姊性格、能力或商業成果的評價。
- 對外發布前，先確認物品照片、個資、聯絡方式與價格是否可以公開。

## 目前不能做的事

- 不能根據目前素材模擬佳佳學姊的語氣或人格。
- 不能聲稱她有固定的定價、選品、拍攝、談價或出貨系統。
- 不能聲稱二手變現一定比捐贈或丟棄更好。
- 不能把一次「直接掛上二手拍賣平台」的行動，升格成已驗證的產品規則。

## 更新條件

收到佳佳學姊新的原始分享、實際操作紀錄或多次結果後，先加入 `references/evidence.md`，再檢查是否能新增：

- 穩定出現的判斷原則；
- 具體的上架或分流步驟；
- 成交、未成交與時間成本資料；
- 與目前暫定模型不一致的案例。

沒有新證據時，不要為了讓 Skill 看起來完整而擴寫。
